# Smart_Student

«Умный ученик» — интерактивное учебное приложение для 4–5 классов с адаптивной сложностью заданий и сохранением прогресса в Supabase.

Текущие направления:
- математика: 4 и 5 класс;
- русский язык: 4 и 5 класс;
- адаптивные задания, прогресс ученика и родительская статистика;
- основной фирменный логотип: `smart-student-logo-v3.png`;
- брендовый слой интерфейса: `brand-v3.css` и `brand-v3.js`.

Production-развёртывание выполняется Vercel автоматически из ветки `main`.

Локальные IDE-файлы, `.vercel`, `node_modules` и системные файлы исключены через `.gitignore`.
