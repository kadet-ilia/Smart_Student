# Smart_Student

«Умный ученик» — интерактивное учебное приложение для 4–5 классов с адаптивной сложностью заданий и сохранением прогресса в Supabase. Новый интерфейс «Студия решений» работает на Next.js 15 и React 19, сохраняя существующие учебные программы и генераторы задач.

Текущие направления:
- математика: 4 и 5 класс;
- русский язык сохранён в legacy-версии и помечен «Скоро» в новом интерфейсе;
- адаптивные задания, синхронизация прогресса между устройствами и восстановление PIN по родительскому коду;
- основной фирменный логотип: `smart-student-logo-v3.png`;
- дизайн-система нового интерфейса: `app/globals.css` и `DESIGN_SYSTEM.md`.

## Локальный запуск

```bash
npm install
npm run dev
```

Для production рекомендуется задать `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` по образцу `.env.example`. В репозитории сохранён только публичный резервный ключ Supabase; service-role ключ приложению не требуется.

Проверки перед публикацией:

```bash
npm run typecheck
npm run build
```

Спецификация интерфейса находится в `DESIGN_SYSTEM.md`, результаты визуального QA — в `design-qa.md`.

Production-развёртывание выполняется Vercel автоматически из ветки `main`.

Локальные IDE-файлы, `.vercel`, `node_modules` и системные файлы исключены через `.gitignore`.
